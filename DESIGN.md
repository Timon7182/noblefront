# Design

Визуальная система Noble. Концепция — «медленная роскошь»: тон салона, а не маркетплейса. Токены живут в `tailwind.config.js`, базовые классы — в `src/assets/main.css`.

## Theme

Светлая, одна. Тёплый off-white фон, почти-чёрные чернила, глиняный акцент. Стратегия цвета — **restrained**: акцент занимает меньше 10% поверхности, работу делают типографика и фотографии товара.

## Color

| Токен | Значение | Роль |
|---|---|---|
| `bg` | `#FAF7F2` | Основной фон страницы |
| `surface` | `#F2EDE5` | Подложка карточек, глава «бренды» |
| `surface2` | `#ECE5D8` | Более плотная подложка |
| `ink` | `#1A1A18` | Основной текст, кнопки-заливки, анно-полоса |
| `ink2` | `#6B655C` | Вторичный текст, описания |
| `ink3` | `#9A948A` | Третичный: перечёркнутые цены, подписи |
| `line` | `#E5DFD4` | Все разделители (толщина всегда 1px) |
| `clay` | `#9A6B4F` | Акцент: буквица, hover, выделение текста |
| `claysoft` | `#B8896E` | Кавычки, мягкие акценты |
| `cream` | `#EFE7D6` | Текст на тёмном (анно-полоса) |

Контраст: `ink` на `bg` — 15:1; `ink2` на `bg` — 5.4:1; `ink3` только для нетекстовых ролей и перечёркнутых цен.

## Typography

Две гарнитуры, контраст по оси serif/sans:

- **Cormorant Garamond** (`.serif`, `font-serif`) — заголовки, названия товаров, цены, цитаты, номера `N° 01`. Вес 300–400, курсив для номеров и цитат.
- **Inter** (`font-sans`, по умолчанию для `body`) — интерфейс, кнопки, метки, описания. Вес 300–500.

Шкала заголовков — fluid `clamp()`: hero `clamp(40px,6vw,88px)`, глава `clamp(30px,4vw,52px)`, подзаголовок `clamp(19px,2.2vw,28px)`. Метки и кнопки — 11–12px uppercase с трекингом 0.2–0.3em. Логотип — трекинг `tracking-logo` (0.4em).

Ширина колонки текста: до 52ch для прозы, `max-w-prose` (50ch) для описаний.

## Components

Базовые классы в `main.css`:

- `.btn-solid` — тёмная pill-кнопка (основное действие: в корзину, оформить).
- `.btn-line` — контурная pill-кнопка (вторичное действие).
- `.section-label` — метка главы с линиями по бокам.
- `.cat-num` — каталожный номер `N° 01` курсивным серифом.
- `.old-price-quiet` — старая цена: перечёркнута, `ink3`, без красных плашек.
- `.rail` — горизонтальная лента: поля совпадают с колонкой страницы, карточки уезжают за правый край.
- `.loader` — тонкое кольцо загрузки с глиняным сегментом.
- `.field-label` / `.field-input` / `.field-error` — поле формы: подпись капителью, линия вместо коробки, ошибка цветом `danger`.
- `.combo-menu` / `.combo-option` — выпадающий список комбобокса.
- `.quiet-scroll` — прокручиваемый список без грубой системной полосы: бегунок проявляется при наведении. Тем же приёмом стилизованы выпадающие меню категорий.

Формы собраны из двух компонентов: `TextField.vue` (подпись, поле, ошибка) и `ComboField.vue` (поиск с выпадающим списком, навигация стрелками, Esc, клик вне поля). Валидация — `src/validation.js`: маска казахстанского номера `+7 (7XX) XXX-XX-XX`, проверка почты и имени. У числовых полей отключены стрелки-спиннеры, единица (`₸`) стоит в самом поле.

Карточка товара: изображение 4/5 на `surface`, номер и метка скидки — светлые плашки в углах, круглая кнопка «+» появляется при наведении (на тач-устройствах видна всегда), под изображением — название серифом и цена.

## Layout

Колонка страницы: `max-w-page` (1320px) + `px-5 xl:px-8`. Вертикальный ритм между главами — `my-24 md:my-36`. Сетка каталога: 2 колонки на мобильном, 3 на xl, 4 на 2xl. Шапка — две строки: логотип по центру, категории отдельной строкой со скроллом при переполнении.

Z-index — семантическая шкала: `nav` 40, `dropdown` 50, `modal-backdrop` 60, `modal` 70.

## Motion

Три директивы в `src/directives/motion.js`, подключены глобально в `main.js`:

- `v-reveal` / `v-reveal="1..3"` — появление главы при скролле. Скрывает **только** то, что при монтировании ниже экрана, плюс страховочный таймер 2.5 с: глава физически не может остаться пустой.
- `v-parallax="8"` / `v-parallax="{ x: 4, y: 10 }"` — параллакс на GSAP ScrollTrigger. Рамкой служит ближайший `[data-parallax-frame]`; изображение внутри — `.parallax-cover` (высота 124%, запас хода).
- `v-tilt="5"` — 3D-наклон карточки за курсором. Отключается на тач-устройствах.

Кривая — `ease-out-lux` (`cubic-bezier(0.2, 0.7, 0.2, 1)`), длительности 0.3–1.4 с. Никакого bounce.

`prefers-reduced-motion: reduce` отключает параллакс, наклон, ken-burns и reveal целиком — контент отдаётся статикой.
